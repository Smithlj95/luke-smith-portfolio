# Luke Smith Portfolio

A professional personal portfolio for Luke Smith, focused on computing and cybersecurity.

## Before publishing
Open `index.html` and replace:
- `YOUR-EMAIL@example.com`
- `YOUR-LINKEDIN-URL`

You can also add project links and update the Projects section as you complete new work.

## Publish with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository named `luke-smith-portfolio`.
3. Upload `index.html`, `style.css`, `script.js` and this README.
4. In the repository, open Settings → Pages.
5. Choose Deploy from a branch, select `main` and `/root`, then save.
6. Your site will be available at your GitHub Pages address.
